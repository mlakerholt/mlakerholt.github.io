# Evozyme 1.0.0

9 September 2026

- Seven-stage campaign workflow with equipment/software checklists, coverage and cost planning, mapped screening review, confirmation evidence, and linked rounds.
- Browser storage, versioned campaign backups, unchanged raw-file retention, analysis snapshots, and CSV/JSON/report exports.
- Searchable handbook with citations, three worked examples, PowerPoint, workbook, templates, and Python reference downloads.
- Site-matched retro styling, keyboard focus, labeled forms, mobile layouts, and printable campaign reports.
- Synthetic LipA example reproducing the reference screening and confirmation arithmetic.

The first release supports toolkit-format 96-well linear-rate screens. Broader plate formats, endpoint/nonlinear assays, pooled cross-plate inference, instrument adapters, cloud collaboration, and guaranteed offline installation are future extensions. The available browser verification is documented in `VERIFICATION.md`.
